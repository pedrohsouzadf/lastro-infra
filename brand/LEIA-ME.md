# Kit de marca LASTRO

Todos os arquivos foram gerados a partir da geometria vetorial da marca. Os `.svg`
são a fonte da verdade — o texto está convertido em curvas, então abrem em qualquer
máquina sem precisar da fonte Space Grotesk instalada.

## Instagram

| Arquivo | Onde usar |
|---|---|
| `instagram-avatar-1080.png` | **Foto de perfil.** Símbolo centralizado com halo verde. É a versão recomendada — o Instagram corta em círculo e o símbolo já está dentro da área segura. |
| `instagram-avatar-anel-1080.png` | Alternativa com anel verde. O anel encosta na borda; use só se quiser o contorno mesmo correndo risco de corte em telas menores. |
| `instagram-avatar-claro-1080.png` | Versão em fundo branco, caso queira um perfil claro. |
| `instagram-post-template-1080.png` | Template de post 1080×1080. |
| `instagram-story-template-1080x1920.png` | Template de story 1080×1920. |
| `assinatura-post-1200.png` | Assinatura pequena com fundo transparente, para o rodapé de posts em fundo escuro. |
| `assinatura-post-escura-1200.png` | Mesma coisa, para posts em fundo claro. |

## Logo

**Horizontal** (uso padrão — header, assinatura de e-mail, apresentações):
`logo-horizontal.svg/png` (transparente) · `-fundo-escuro` · `-fundo-claro` ·
`-mono-branco` (chapado, para foto ou fundo colorido) · `-mono-escuro`

**Vertical** (quando o espaço é mais alto que largo — cartão, adesivo, story):
`logo-vertical.svg/png` · `-fundo-escuro` · `-fundo-claro`

**Símbolo isolado** (favicon, avatar, marca d'água, padrão de fundo):
`simbolo.svg` · `simbolo-1024.png` · `simbolo-512.png` · `simbolo-mono-branco` ·
`simbolo-mono-escuro` · `icone-app-1024.png` (quadrado arredondado, para ícone de app)

## Regras de uso

- **Área de respiro:** deixe em volta da logo, no mínimo, a altura de uma camada do símbolo.
- **Tamanho mínimo:** logo horizontal a partir de 120px de largura; abaixo disso use só o símbolo.
- Não recolora, não incline, não aplique sombra e não separe o símbolo do wordmark
  criando um arranjo novo — para arranjo vertical existe a versão pronta.
- Em foto ou fundo colorido, use a versão **mono**, nunca a colorida.

## Paleta

| Cor | Hex | Uso |
|---|---|---|
| Verde técnico | `#39D353` | Acento único: crescimento, saúde, solução |
| Fundo | `#0D1117` | Base, estabilidade, profundidade |
| Off-white | `#F7F7F5` | Texto, clareza, confiança |
| Cinza | `#6B7280` | Secundário, suporte, neutro |
| Alerta | `#C0392B` | Risco, problema — uso pontual |

## Tipografia

- **Space Grotesk** — títulos e wordmark
- **Inter** — texto corrido
- **JetBrains Mono** — código, dados, labels técnicos

Todas gratuitas no Google Fonts.
